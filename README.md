# Medical Vocab Quiz (医学英単語 4択クイズ)

`medical_vocabulary_list.csv` に収録されている全1190単語を対象とした、React 19 + TypeScript + Vite 8 による医学英単語4択クイズWebアプリケーションです。

## 特徴
- **4択クイズ形式**: 問題として提示される英単語に対して、正答の意味1つと同単語表からランダムに選ばれたダミー誤答3つの4択から回答します。
- **カテゴリ（テーマ）選択**: 遺伝・遺伝子、細胞・解剖・生理、疾患・治療・臨床、公衆衛生・疫学、免疫・感染症など22のテーマ別、または全テーマミックス出題。
- **2つのゲームモード**:
  - 🎯 **標準モード**: 5問 / 10問 / 20問 / 30問の規定数クイズ
  - 🔥 **エンドレスモード**: 間違えるまで連続出題されるハイスコアモード
- **辞書・単語帳モーダル**: 全1190単語を検索・フィルタリングして閲覧可能
- **結果＆復習**: 得点・正答率・解答時間と、間違えた問題の振り返り表示
